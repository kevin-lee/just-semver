* Upgrade Scala 2.13: `2.13.16` => `2.13.17` (#289)


### Improvement

* `compareElems` (used to compare pre-release identifiers and `Dsv` values) now uses the standard library's lexicographic `Seq` ordering (#289)

  The results do not change. The new code uses iterators instead of repeated `tail`, so it no longer costs O(n²) for `Seq` types like `ArraySeq`.
